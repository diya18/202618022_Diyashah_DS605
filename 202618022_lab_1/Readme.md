PROJECT OVERVIEW:
This project is a complete web scraping and data analysis pipeline for book data. The project begins by extracting book information from Books to Scrape using Python and Scrapy, followed by data cleaning, feature engineering, analysis, and visualization using Pandas and other Python libraries.
WEB SCRAPING USING SCRAPY:
A Scrapy spider was created to scrape book information from the website. The spider follows the catalog pages and visits individual book pages to collect relevant details such as title, category, price, rating, availability, product description, UPC, number of reviews, and product URL. The scraped data was then exported into a CSV file for further processing and analysis.
DATA CLEANING AND FEATURE ENGINEEING:
The extracted dataset was loaded using Pandas and inspected for missing values and duplicate records. Extra spaces were removed, duplicate books were handled using UPC, prices were converted into numerical values, ratings were converted into numbers, and stock availability was extracted into a usable format.New features were created to make the data more useful for analysis. These include description word count, price band, and affordability score.
DATA ANALYSIS AND VISUALIXATION:
Several analyses and visualizations were performed to understand the book dataset. These included price distribution, rating distribution, average price by category, price versus rating, stock patterns, and a word cloud of book descriptions. Statistical summaries were also used to identify highly rated books and differences between categories.
KEY INSIGHTS:
The analysis showed that book prices vary across categories, while many books fall within a moderate price range. The rating analysis helped identify highly rated books and compare ratings with prices. Category-level analysis showed differences in average prices and stock availability. The price-versus-rating analysis also helped determine whether higher-priced books necessarily have higher ratings.
