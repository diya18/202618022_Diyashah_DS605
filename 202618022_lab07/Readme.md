## Image Representation, PCA, Eigenfaces and Face Recognition

## Objective

The objective of this assignment is to represent face images numerically, reduce their dimensionality using Principal Component Analysis (PCA) and eigenfaces, perform face recognition in the reduced feature space, and compare the results with traditional machine-learning classifiers.

## Dataset

This project uses the AT&T Database of Faces, also known as the ORL Database of Faces. The dataset contains grayscale face images organized by subject. The commonly used ORL collection consists of 40 subjects with 10 images per subject, giving 400 images in total. Each image has dimensions of 112 × 92 pixels.

The dataset is organized into subject folders named `s1` through `s40`, with the corresponding `.pgm` images inside each folder.

## Part A — Image Representation

- Load the face images as grayscale pixel matrices.
- Inspect image dimensions and pixel intensity values.
- Flatten each image into a feature vector and construct the complete image matrix with subject labels.
- Create a reproducible train-test split with every subject represented in both sets.

Images 1–7 of each subject are used for training, while images 8–10 are used for testing.

## Part B — PCA, Eigenfaces and Compression

- Center the training data using the mean face calculated from the training images.
- Implement PCA using NumPy linear-algebra operations.
- Compare dual-covariance eigendecomposition with Singular Value Decomposition (SVD).
- Plot cumulative explained variance and determine the number of components needed to preserve at least 90% of the variance.
- Visualize eigenfaces and project images into PCA space.
- Reconstruct face images using the retained principal components.
- Estimate the reduction in per-image coefficient storage.

**Implementation requirement:** PCA and eigenface calculations are implemented using NumPy linear-algebra operations rather than `sklearn.decomposition.PCA`.

## Part C — Recognition in PCA Space

- Project test images into the retained PCA feature space.
- Identify the nearest training face using Euclidean distance.
- Calculate face-recognition accuracy.
- Visualize examples of correct and incorrect matches.
- Compare PCA-space recognition with nearest-neighbor matching using raw pixel features.

## Part D — Traditional Machine Learning

- Train at least two traditional classifiers using PCA features.
- Compare K-Nearest Neighbors (KNN) and Logistic Regression with similarity-based recognition.
- Evaluate accuracy, macro precision, macro recall, and macro F1 score.
- Experiment with different numbers of retained components and KNN settings.

Scikit-learn is used for the classifier comparison, but not to perform PCA.

## Methodology

The project follows these steps:

1. Load grayscale face images and inspect pixel matrices.
2. Flatten each image into a numerical feature vector.
3. Create a deterministic training and testing split.
4. Calculate the training mean face and center the data.
5. Compute principal directions using covariance eigendecomposition and SVD.
6. Analyze explained variance and select a reduced feature representation.
7. Visualize eigenfaces and reconstruct images from PCA scores.
8. Perform nearest-neighbor face matching in PCA space.
9. Train traditional classifiers using PCA features.
10. Compare recognition performance and discuss the experimental results.

## Results and Discussion

The results are evaluated using the measurements generated by the notebook.

The following aspects are analyzed:

- **Image representation:** Original image dimensions and the size of the flattened feature matrix.
- **Dimensionality reduction:** Number of principal components required to preserve at least 90% of the variance.
- **PCA comparison:** Similarities between the explained-variance results obtained using covariance eigendecomposition and SVD.
- **Image reconstruction:** Visual quality of reconstructed faces and the corresponding reconstruction error.
- **Face recognition:** Accuracy obtained using PCA-space nearest-neighbor matching compared with raw-pixel matching.
- **Classifier comparison:** Performance of KNN, Logistic Regression, and similarity-based recognition.
- **Parameter tuning:** Effect of the number of retained components and KNN settings on recognition performance.
- **Compression trade-off:** Relationship between dimensionality reduction, reconstruction quality, and recognition accuracy.

The final report should use the actual numerical results generated by the notebook rather than assuming results from another run.

## Conclusion

This assignment demonstrates how face images can be represented as high-dimensional numerical vectors and transformed into a compact feature representation using Principal Component Analysis. The eigenfaces provide a visual understanding of the major directions of variation in the training images, while image reconstruction illustrates how retaining fewer principal components affects the quality of the reconstructed faces.

Face recognition in PCA space enables comparisons between images using a reduced set of features instead of all the original pixel values. Comparing PCA-based recognition with raw-pixel matching and traditional machine-learning classifiers helps evaluate the effectiveness of dimensionality reduction for face-recognition tasks.

The experiments also demonstrate that the number of retained principal components and the choice of classifier can influence recognition performance. Overall, this assignment connects image representation, linear algebra, dimensionality reduction, image reconstruction, and supervised classification through a practical face-recognition application.
